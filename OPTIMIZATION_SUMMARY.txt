CUDA Abstraction Kernel Optimization Summary
================================================================================

OPTIMIZATION GOAL:
  将abstraction_kernel中的约束检查从for循环改为掩码+四维前缀和方式

CHANGES MADE:
================================================================================

1. 新增函数：build_constraint_mask_kernel
   - 位置：cuda/kernels.cu:190-201
   - 功能：为所有状态并行构建约束满足掩码
   - 输入：state_grid, constraint_params
   - 输出：constraint_mask[state_count]
   - 并行度：state_count个线程

2. 新增函数：d_box_satisfies_constraint_fast
   - 位置：cuda/kernels.cu:75-92
   - 功能：使用前缀和O(1)时间检查盒内约束
   - 替代：原来的d_box_satisfies_constraint（for循环）
   - 方法：比较盒内满足约束的状态数与有效状态数

3. 修改函数：abstraction_kernel
   - 位置：cuda/kernels.cu:132-188
   - 新增参数：
     * PrefixLayout4D layout
     * const PrefixCount* prefix_constraint
     * const PrefixCount* prefix_valid
   - 修改：调用d_box_satisfies_constraint_fast替代d_box_satisfies_constraint

4. 修改函数：run_case_cuda_u32
   - 位置：cuda/kernels.cu:492-897
   - 新增显存分配：
     * d_constraint_mask (state_count × 1字节)
     * d_prefix_constraint (prefix_layout.total_size × 8字节)
   - 新增计算步骤：
     * build_constraint_mask_kernel
     * build_prefix_on_device(d_constraint_mask → d_prefix_constraint)
     * build_prefix_on_device(d_valid_mask → d_prefix_valid)
   - 修改abstraction_kernel调用，传递前缀和参数

PERFORMANCE IMPROVEMENTS:
================================================================================

时间复杂度改进：
  原始：O(pair_count × avg_box_volume)
  优化：O(state_count + pair_count)
  
  对于平均盒子大小B的情况，加速比约为B倍
  （对于大盒子可能是10-100倍）

显存增加：
  约2-4MB（对于204800状态的网格）
  - constraint_mask: ~200KB
  - prefix_constraint: ~2-4MB

ALGORITHM DETAILS:
================================================================================

核心思想：
  1. 预构建约束掩码：constraint_mask[i] = satisfies_constraint(state[i])
  2. 构建约束前缀和：prefix_constraint[i,j,k,l] = sum(constraint_mask)
  3. 快速查询：使用16个顶点的容斥原理O(1)查询盒内满足约束的状态数
  4. 判断条件：constraint_count == valid_count

前缀和查询方法（参考可达集合迭代）：
  - 使用d_query_box_single进行16个顶点的容斥计算
  - 处理wrap-around情况（角度维度）
  - 总时间复杂度：O(1)相对于盒的大小
