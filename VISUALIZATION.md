# Visualization Documentation

## Overview

Python scripts for visualizing symbolic control results from HDF5 output files.

## Required Dependencies

```bash
pip3 install h5py numpy matplotlib scikit-image
```

## Visualization Scripts

### `scripts/plot_results.py`

Main script for plotting reachable sets, controllers, and 3D visualizations.
By default, plots are saved in a `plots` directory in the current working directory.

**Usage:**
```bash
# Plot reachable set (saved to ./plots/)
python3 scripts/plot_results.py results/case.h5 --field reachable

# Plot controller for fixed (theta, speed) slice (saved to ./plots/)
python3 scripts/plot_results.py results/case.h5 --field controller --theta-idx 2 --speed-idx 1

# 3D set visualization over (x, y, theta) (saved to ./plots/)
python3 scripts/plot_results.py results/case.h5 --plot-mode sets3d

# Fixed speed mode for 3D plots (saved to ./plots/)
python3 scripts/plot_results.py results/case.h5 --plot-mode sets3d --speed-mode fixed

# Custom output path (overrides default plots directory)
python3 scripts/plot_results.py results/case.h5 --plot-mode sets3d --output ./my_plots/result.png


# example

python3 scripts/plot_results.py results/hyperbolic_demo_gpu.h5 --plot-mode sets3d --run gpu --candidate-color blue --candidate-alpha 0.8

```

**Arguments:**
- `--output` or `-o`: Output file path for saved figure (default: ./plots/<auto-generated-name>.png)
- `--field`: `reachable`, `candidate`, `controller`, or `reach_step`
- `--speed-mode`: `fixed` or `project` (for 3D plots; note: documentation previously said 'mean', but code uses 'project' and 'fixed')

### `scripts/plot_convergence.py`

Specialized for GPU convergence and performance analysis.

**Usage:**
```bash
# Basic convergence plot
python3 scripts/plot_convergence.py results/case_gpu.h5

# All figures (convergence, timing, efficiency)
python3 scripts/plot_convergence.py results/case_gpu.h5 --show-all

# Save to directory
python3 scripts/plot_convergence.py results/case_gpu.h5 --show-all --output-dir plots/
```

**Output Figures:**
1. **Convergence analysis**: Cumulative certified candidates, newly certified per iteration
2. **Performance analysis**: Iteration timing breakdown, kernel-level timings
3. **Efficiency metrics**: Throughput (states/ms), cumulative efficiency

### `scripts/example_gpu_analysis.sh`

One-click script for complete GPU analysis:
```bash
./scripts/example_gpu_analysis.sh
```

Runs GPU solve and generates all visualization plots.

## HDF5 Data Structure for Visualization

```
results/*.h5
├── /state           # Grid metadata (lb, ub, eta, shape, strides, total_size, wrap_dim)
├── /input           # Input grid metadata
├── /config          # Case configuration
├── /result/{cpu,gpu}  # Results
│   ├── valid_mask[states]
│   ├── candidate_mask[states]
│   ├── reachable_mask[states]
│   ├── controller[states]
│   └── reach_step[states]
├── /abstraction     # GPU-only: pair_min_flat, pair_max_flat, valid
├── /iterations      # GPU-only: per-iteration statistics
└── /timings         # GPU-only: kernel-level timings
```

## Data Loading in Python

```python
import h5py

with h5py.File("results/case.h5", "r") as f:
    state = f["state"]
    lb = state["lb"][:]
    ub = state["ub"][:]
    shape = state["shape"][:]
    
    result = f["result"]["gpu"]
    reachable = result["reachable_mask"][:]
    controller = result["controller"][:]
    
    # Reshape to 4D
    reachable_4d = reachable.reshape(shape)
```

## Common Visualization Patterns

### 2D Slice Visualization

```python
# Plot x-y slice at fixed (theta, speed) indices
idx_theta = 10
idx_speed = 5
slice_2d = reachable_4d[:, :, idx_theta, idx_speed]
plt.imshow(slice_2d.T, origin='lower', extent=[x_min, x_max, y_min, y_max])
```

### 3D Isosurface

```python
from skimage import measure

# Extract isosurface at 0.5 threshold
verts, faces, _, _ = measure.marching_cubes(reachable_4d.astype(float), 0.5)
# Plot with matplotlib or export to mesh file
```

### Controller Field Visualization

```python
# Color-coded controller values
plt.scatter(states_x, states_y, c=controller[controller >= 0], cmap='hsv')
```
